> **Modo TDD estricto.** Cada tarea que produce código de producción arranca por su test en rojo. Las tareas están ordenadas por dependencia: dominio puro → borde de red → presentación → composición → retiro. El comando de la suite es `npm run test:run` desde `wasa-landing/`; el de tipos, `npm run build` (`tsc -b && vite build`).
>
> **Gate de governance (MEDIO).** Las tareas 1.1 y 8.1 son puntos de detención explícitos: se consulta al usuario antes de seguir.
